# Letter 📝

[![License: GPL v3](https://shields.io)](https://gnu.org)
[![Python Version](https://shields.io)](https://python.org)

**Letter** est un éditeur de documents `.docx` open source conçu pour modifier vos fichiers tout en préservant rigoureusement le formatage manuel original de Microsoft Word.

## ✨ Caractéristiques

*   **Édition de texte** : Modifiez le contenu de vos fichiers `.docx` sans quitter l'application.
*   **Fidélité de formatage** : Contrairement à de nombreux éditeurs tiers, Letter s'efforce de conserver les styles, marges et mises en forme complexes propres aux documents MS Word.
*   **Open Source** : Entièrement transparent et personnalisable.
*   **Léger** : Développé intégralement en Python pour une exécution fluide.

## 🚀 Installation

### Prérequis
*   [Python 3.8+](https://python.org)

### Clonage du dépôt
```bash
git clone https://github.com/slalonde00/Letter
cd Letter
```

### Installation des dépendances
*(Il est recommandé d'utiliser un environnement virtuel)*
```bash
pip install -r requirements.txt
```

## 🛠️ Utilisation

Pour lancer l'application, exécutez le script principal :

```bash
python Letter.py
```
